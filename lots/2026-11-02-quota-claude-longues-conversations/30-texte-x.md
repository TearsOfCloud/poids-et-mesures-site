# Fil X (texte seul)

1/ Ton quota Claude fond vite ? Un cas de la semaine montre un coût caché : pour écrire une étiquette de 3 à 5 mots, Claude Code renvoie au modèle tout l'historique d'un agent, toutes les ~30 s (selon Flamerix, confirmé sur le mécanisme par Anthropic).

2/ Le chiffre fait débat. Flamerix : 15 à 20 % des tokens sur son équipe. Anthropic : environ 2 % du coût en moyenne, 6 % dans le terminal, et un correctif (cache) déployé. Un token = un petit morceau de texte que l'IA compte.

3/ Ce que ça t'apprend, d'après l'aide d'Anthropic : la longueur de la conversation, les pièces jointes, les outils et le niveau d'effort pèsent sur ton usage. Trois réflexes : nouveau sujet = nouvelle conversation ; questions liées = un message ; connecteurs inutiles = coupés.

4/ Réserve : ces réflexes viennent de l'aide de Claude, pas vérifiés chez les autres assistants. Sources : gist Flamerix AI, commentaire Anthropic sur Hacker News, centre d'aide Anthropic, Numerama.
