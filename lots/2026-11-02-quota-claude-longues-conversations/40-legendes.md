# Légendes

**Instagram** : Ton quota Claude fond plus vite que prévu ? Un cas de cette semaine montre le principe : relire un long historique coûte, et la longueur de la conversation compte dans ton usage (c'est écrit dans l'aide d'Anthropic). Trois réflexes : nouveau sujet = nouvelle conversation ; questions liées = un seul message ; connecteurs et recherche web inutiles = coupés. Les chiffres divergent : Flamerix annonce 15 à 20 %, Anthropic mesure environ 2 % (6 % dans le terminal). Sources : Flamerix AI, Anthropic (aide + Hacker News), Numerama. Ces conseils viennent de l'aide de Claude.
