Tu réexpliques la même tâche à ton assistant IA chaque semaine ? GitHub vient de publier un guide sur les « skills » : une notice écrite une fois, que l'IA relit à chaque fois.

2/4
Concrètement, selon GitHub : un dossier avec un fichier SKILL.md. Il dit quand utiliser la skill et comment faire la tâche. Exemple cité : un vérificateur séparé, parce qu'une IA qui relit son propre travail se laisse influencer.

3/4
Limite à retenir : une skill est une notice, pas une clé. Elle peut décrire comment interroger une base de données, mais elle ne donne pas l'accès. Les droits viennent de l'outil qui l'exécute.

4/4
À essayer : prends ta tâche la plus répétée, note ce qu'il faut, où ça s'arrête, ce que tu vérifies. Teste avec un autre assistant. Source : blog GitHub, 12/11/2026. Aucune mesure de gain n'est donnée.
