# Fil X (4 posts, texte seul, ≤ 280 caractères)

1/4
Depuis le 24/11, selon la doc d'Anthropic, Claude peut transformer un « artifact » (la petite appli qu'il construit dans le chat) en vraie appli Mac ou Windows : fenêtre, icône, comme les autres. En bêta, comptes gratuits inclus.

2/4
Exemples cités par Anthropic : un minuteur Pomodoro dans la barre de menus, un rappel pour s'étirer chaque heure, une appli Windows qui renomme des photos par date. Installation : clic droit sur l'artifact, « Install as app ».

3/4
Le point à retenir : l'appli demande avant chaque pouvoir (notifications, raccourcis, barre de menus). Le niveau « accès complet » permet de modifier ou supprimer des fichiers. Anthropic précise ne pas vérifier les applis avant installation.

4/4
Réflexe : refuse les droits dont l'outil n'a pas besoin. Désinstaller : Fichier > Apps > Uninstall. C'est une bêta, nous ne l'avons pas testée, la page ne donne aucun chiffre. Source : Claude Help Center.
