# Carrousel 4:5, 8 slides (analyse, pas une copie du Reel)

1. **Titre : Ton IA lit-elle vraiment ton tableau ?** Corps : Nvidia a publié le 26 novembre 2026 un modèle qui lit des pages. Ce qu'il explique sur les tableaux et les graphiques vaut pour tout le monde.
2. **Titre : Une page, c'est une image.** Corps : Quand tu donnes un PDF scanné ou une capture, l'IA doit d'abord reconnaître ce qu'elle voit : titres, paragraphes, tableaux, graphiques.
3. **Titre : Ce que fait ce modèle.** Corps : Selon Nvidia, il rend le contenu dans l'ordre de lecture, classe chaque bloc (titre, tableau, graphique) et indique où il se trouve sur la page.
4. **Titre : Le tableau, point fragile.** Corps : Nvidia l'écrit : une ligne ou une colonne décalée peut changer totalement l'interprétation. Un chiffre juste dans la mauvaise colonne reste faux.
5. **Titre : Le graphique : une estimation.** Corps : Sans valeurs écrites, le modèle déduit les chiffres des axes et de la hauteur des barres. Exemple de Nvidia : 18, 27, 39 et 54. Estimer n'est pas lire.
6. **Titre : Ce que Nvidia a mesuré.** Corps : Après un second entraînement, les pages où le modèle boucle passent de 126 à 29 ; le score global de 66,24 à 71,38. Ce sont des tests de Nvidia, sur des versions de développement.
7. **Titre : Ce qu'on ne sait pas.** Corps : L'article parle d'un modèle de Nvidia, pas de ChatGPT, Claude, Gemini ou Le Chat. Aucun test indépendant lu. Nous n'avons rien mesuré nous-mêmes.
8. **Titre : Ton réflexe.** Corps : Demande à l'IA de recopier le tableau en texte, puis vérifie trois lignes. Graphique sans chiffres : demande des valeurs approximatives et lesquelles sont estimées. Fichier Excel disponible : colle les cellules. Source : Nvidia, 26/11/2026.
